# M.S Отчёт: iOS-приложение

Приложение анализирует продажи кофейни по выгрузке из кассы и показывает, где теряются деньги, в рублях в месяц. Файл обрабатывается на телефоне и никуда не отправляется.

## Запуск на iPhone

1. Нужен Mac с **Xcode 16** или новее.
2. Откройте `MSReport.xcodeproj`.
3. Слева выберите проект **MSReport**, затем вкладку **Signing & Capabilities**. В поле **Team** выберите свой Apple ID. Если поле пустое, добавьте аккаунт: Xcode → Settings → Accounts.
4. Подключите iPhone, выберите его вверху и нажмите **Run** (▶).
5. При первом запуске на iPhone откройте «Настройки → Основные → VPN и управление устройством» и доверьте разработчику.

## Сборка через GitHub (без Mac)

- **Сборка** (`.github/workflows/build.yml`) запускается при каждом изменении и проверяет, что код компилируется. Аккаунт Apple для неё не нужен.
- **TestFlight** (`.github/workflows/testflight.yml`) запускается вручную: Actions → TestFlight → Run workflow. Она собирает, подписывает и отправляет приложение в TestFlight.

Секреты для TestFlight задаются в Settings → Secrets and variables → Actions:

| Секрет | Где взять |
|---|---|
| `TEAM_ID` | developer.apple.com → Account → Membership details → Team ID |
| `ASC_KEY_ID` | App Store Connect → Users and Access → Integrations → App Store Connect API: ключ с ролью **Admin**, колонка Key ID |
| `ASC_ISSUER_ID` | там же, Issuer ID над таблицей ключей |
| `ASC_KEY_P8` | всё содержимое скачанного файла `AuthKey_XXXX.p8`, вместе со строками BEGIN и END |

## Публикация в App Store

1. Оформите **Apple Developer Program** (developer.apple.com, $99 в год).
2. Если нужно, поменяйте **Bundle Identifier** (сейчас `ru.mscompany.salesreport`). Он должен быть уникальным.
3. В App Store Connect создайте приложение с тем же Bundle ID.
4. В Xcode выберите устройство **Any iOS Device**, затем **Product → Archive** и **Distribute App → App Store Connect**.
5. Заполните карточку: скриншоты, описание, политику конфиденциальности. В разделе «Конфиденциальность» выберите **«Данные не собираются»**.

## Что умеет

- Загружает **Excel (.xlsx)**, **CSV**, а также .xls-выгрузки iiko и ОФД, которые на деле являются XML или HTML. Старый двоичный .xls нужно пересохранить в .xlsx.
- Сам находит строку заголовков и определяет столбцы: дата, время, сумма, цена, количество, товар, категория, точка, номер чека, скидка, себестоимость. Перед построением отчёта столбцы можно поправить. Обязательны только дата и сумма.
- Отчёт содержит:
  - сумму «Можно вернуть в месяц»;
  - главные находки;
  - выручку по дням, часам и дням недели;
  - сравнение точек сети;
  - топ позиций с ABC-анализом;
  - категории.
- Находки: пустые часы, слабые дни, отстающие точки, падение среднего чека или выручки, позиции, которые продаются хуже, чеки из одной позиции (недобор допродаж), скидки, возвраты, низкая маржа, лишние позиции в меню.
- Экспорт отчёта в PDF через кнопку «Поделиться».
- Пример отчёта на демоданных: кнопка «Посмотреть на примере».
- Кнопка «Хочу полный разбор» ведёт в бот @ms_sales_report_bot.

## Структура

```
MSReport/
  App/        точка входа, цвета, форматирование
  Model/      модели и хранение отчётов
  Import/     чтение xlsx/csv/xml/html, разбор чисел и дат, поиск столбцов
  Analysis/   расчёт отчёта и находок, демоданные
  Views/      экраны
```

Сторонних библиотек нет, используются только системные фреймворки (SwiftUI, Charts, Compression). Минимальная версия: iOS 17.
