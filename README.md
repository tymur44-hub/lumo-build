# Lumo для iPhone

Приложение-обёртка мессенджера Lumo (https://lumomess.ru/).
Сборка IPA идёт автоматически на Mac-сервере GitHub: вкладка **Actions → «Собрать IPA» → Run workflow**.
Готовый файл — во вкладке **Releases** (или Actions → сборка → Artifacts).

IPA не подписан: при установке через Sideloadly или AltStore он подписывается вашим Apple ID.
